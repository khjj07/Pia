# Pia

지뢰가 매설된 숲을 탐색하며 아이템을 활용해 생존하는 3D 어드벤처 게임입니다.

**개발 기간**: 2024.09 ~ 2025.02

## 사용 엔진

- Unity (C#)

## 핵심 기술

- 아이템 기반 상호작용 시스템 (삽으로 지뢰 탐지/제거, 도구별 액션 분기)
- 지형 라이팅/포그 등 자연스러운 야외 환경 연출
- 스토리보드 기반 스토리 모드 진행 구조
- 다국어 로컬라이제이션(한국어/영어) 지원
- Addressable Assets를 통한 리소스 관리
- 해상도 대응 및 UI 스케일링 처리

## 기여 개요

팀 프로젝트(4인)로 참여하여 아이템 기반 상호작용 시스템 리팩토링, 지형/환경 연출, 로컬라이제이션, 해상도 대응 및 UI 버그 수정 등을 담당했습니다.

## 프로젝트 구조

```
Assets/
└─ Pia/
   ├─ Graphics/       # 아트 리소스
   ├─ Localization/    # 다국어 텍스트/설정
   ├─ Prefabs/
   ├─ Resources/
   ├─ Scenes/
   └─ Scripts/
      ├─ Game/
      │  ├─ Items/       # 아이템 시스템
      │  ├─ LandMines/    # 지뢰 로직
      │  ├─ Path/         # 이동/경로 처리
      │  ├─ StoryBoard/   # 스토리보드
      │  ├─ StoryMode/    # 스토리 진행
      │  ├─ UI/
      │  └─ Player.cs
      └─ Localize/
```
